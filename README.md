# common-service

Сервис управления приложениями:
- Atredo - сервис приложения Atredo. Подключается к https://github.com/Nefritor/atredo-client
- Constructor - сервис создания упражнений. Подключается к https://github.com/Nefritor/react-sandbox
- MediaInfo - сервис получения информации о мультимедии (не реализовано, идее перенесена сюда: https://github.com/Nefritor/win-media-server)
- TelegramPoll - сервис создания автоматических опрпосов в Telegram
